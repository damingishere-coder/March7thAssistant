# 羁绊链路补全

在“设置 → 货币战争 → 货币战争策略”选择“羁绊链路补全（流派→阵营）”，然后从首页运行“货币战争”。

此策略只针对活动中的“羁绊链路”，固定使用标准博弈紫金1。它扫描全部流派与阵营奖励，跳过已经领取的档位，每局只追一个羁绊。当前羁绊所有档位领取后，再按列表顺序继续；流派优先于阵营。

目标角色名单从游戏羁绊图鉴读取，不根据角色名称猜测羁绊。购买、补给与上阵使用同一份名单；先满足不同目标角色的人数，再用其他角色补位。同名角色的多份拷贝不重复计数。

## 完成与暂停

- 对局胜利后重新扫描奖励页面；只有观察到目标奖励已领取，才结束当前目标。
- 对局失败或通关但羁绊未达标，继续当前目标。连续3局未达标时停止并提示。
- 无法确认结果、职级、角色名单、奖励总进度或页面位置时暂停，保留现场。
- 中断后，只有保存了原目标角色名单，且游戏明确显示标准博弈、紫金1、当前阶段及“继续进度”时，才接续原局；不重置失败次数、不放弃或新开对局。
- 奖励档位数量必须与页面总奖励一致，已领取勾选数量必须与当前进度一致，才允许开局。
- 只有全部档位已领取且总进度已满，才提示完成。

进度保存在本地 `config/currencywars_bonds.json`。中断后再次运行会重新核对游戏页面，历史文件不会替代实际领奖状态。返回货币战争首页、模式选择页或游戏主界面后，从首页重新运行“货币战争”：目标全部奖励（包含紫金档）已实际领取且金额核对一致时，继续下一个目标；否则尝试核对并接续保存的原局。缺少原名单、无法确认旧局或职级不符时，保留原局和失败计数并停止。接续后仍须以真实结算及奖励复核更新计数，结果未知不计败。连续3局未达标的暂停仍需在设置中明确继续。运行中的任务持有文件锁，不能同时启动第二个任务或通过界面重置计数。
